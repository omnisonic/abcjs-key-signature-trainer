How to Use This Trainer

Exercise Types

Note Name: Identify the note letter (with accidentals from the key signature)

Solfege: Identify the scale degree (Do, Re, Mi, etc.)

Key Signature: Identify the key signature shown on the staff

Controls

Note Range: Use the sliders to set the lowest and highest notes you want to practice

Key Selection: Check boxes to choose which keys to practice (or use "All Keys")

Timing: Adjust how long notes and answers are displayed

Ways to Use

Space Bar or Tap: Reveal the answer early, or skip to the next exercise

Auto-Cycle: Exercises automatically advance based on your timing settings

Preview: Drag the note range sliders to see which notes are included

Note Range

The trainer covers all notes on a classical guitar, from D3 (lowest string in drop D) to B6 (highest fret on the high E string). This includes standard tuning and drop D tuning ranges.
